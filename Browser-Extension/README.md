# 🎵 MusicBridge Web Controller (Tarayıcı Eklentisi)
**Geliştirici:** Eren Teknoloji • 2026

Bu eklenti; Chrome, Edge, Brave ve Opera gibi Chromium tabanlı tarayıcılarda çalmakta olan YouTube Music, Spotify Web ve SoundCloud parçalarını otomatik yakalayarak **MusicBridge PC Core** sunucusuyla çift yönlü bağlar.

---

## 🚀 Tarayıcıya Nasıl Yüklenir? (30 Saniyede Kurulum)

1. Tarayıcınızın adres çubuğuna şunu yazın ve Enter'a basın:
   * **Google Chrome:** `chrome://extensions`
   * **Microsoft Edge:** `edge://extensions`
   * **Brave:** `brave://extensions`
2. Açılan sayfanın sağ üst köşesindeki **"Geliştirici Modu" (Developer Mode)** anahtarını açın.
3. Sol üstte beliren **"Paketlenmemiş Öğe Yükle" (Load unpacked)** butonuna tıklayın.
4. Bu klasörü (`Browser-Extension`) seçin.
5. **Tebrikler!** Eklenti yüklendi. Artık tarayıcıda YouTube Music veya Spotify açtığınızda şarkılar anında MusicBridge ile senkronize olacaktır.
